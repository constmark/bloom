# Support Matrix

This page describes executable support in the current repository. Adapter code
or file detection alone does not mean that inference works.

## Status

| Status | Meaning |
| --- | --- |
| `stable` | Reproducible real-model validation and benchmark evidence are published |
| `experimental` | The path executes but still needs broader model or hardware coverage |
| `external-runtime` | Execution requires another process, SDK, or hardware runtime |
| `skeleton` | Inspection and capability diagnostics only; no end-to-end inference |
| `blocked` | The required loader, fixture, dependency, or hardware is unavailable |

## Models and formats

| Model or format | Engine | Status | Notes |
| --- | --- | --- | --- |
| Qwen and Llama text, Safetensors | Candle | `experimental` | Native CPU path. Generated deterministic untrained Qwen2 checkpoints gate exhaustive tokenizer, forward, decoding, OpenAI/Ollama, clean per-input KV state, explicitly marked mechanical embedding/reranking, structured-output, and function paths. A byte-reproducible indexed two-shard variant gates real CPU forward execution through both protocols. Manifest inference and mmap loading share fail-closed validation for bounded regular files, canonical complete shard numbering, exact index/file membership, tensor-header ownership, duplicate tensors, offsets, and `metadata.total_size`. An immutable official SmolLM2 360M Instruct BF16 package gates trained Llama routing, bounded safe ChatML classification, exact instruction following, benchmark evidence, and buffered/streamed OpenAI and Ollama output. CPU materializes these BF16 weights as F32 and reports that runtime footprint; explicit CPU F16/BF16 requests fail before an unsupported matmul. Trained public sharded packages, broader Qwen/Llama checkpoints, Metal, and CUDA still need equivalent evidence |
| BERT sentence encoders, Safetensors | Candle | `experimental` | Native stateless encoder path with CLS/SEP tokenization, bounded length-bucketed padded batches, attention-mask-aware encoder execution and mean pooling, stable input-order restoration, zero KV-cache accounting, and model-bounded context. Bounded Sentence Transformers metadata is fail-closed: unsupported composition modules, pooling modes, unsafe module paths, and dimension mismatches are rejected. An immutable official Apache-2.0 `all-MiniLM-L6-v2` package at a fixed revision gates 384-dimensional output, L2 normalization, variable-length batches, semantic separation, bi-encoder reranking, OpenAI and Ollama current/legacy routes, official clients, and 422 task isolation across five generation routes on CPU. Additional BERT variants, cross-encoder rerankers, Metal, and CUDA still need equivalent evidence |
| Llama, Qwen2, and Qwen3 GGUF | Candle | `experimental` | Architecture-specific quantized loaders. Official Apache-2.0 Qwen2 0.5B Instruct Q4_0, Qwen3 0.6B Q8_0, and SmolLM2 360M Instruct Q8_0 files at fixed revisions and SHA-256 values are CPU-gated for exact architecture routing, deterministic instruction-following output, benchmark reporting, and exact buffered/streamed OpenAI and Ollama chat output. Qwen2 additionally gates GGUF control-token synthesis; SmolLM2 gates Llama-architecture execution and safe ChatML classification. Wider Llama 2/3 checkpoints and quantizations still need equivalent pinned evidence |
| Gemma text, Safetensors | Candle | `experimental` | Native execution |
| Gemma, Mistral, and DeepSeek GGUF | Candle | `blocked` | Requires architecture-specific loaders |
| FunASR and Qwen ASR | Python bridge | `external-runtime` | Requires the model-specific Python environment |
| OpenVINO IR | OpenVINO | `external-runtime` | Requires OpenVINO and exported IR files |
| GGUF fallback and MTP | llama.cpp | `external-runtime` | Launches a compatible `llama-server` |
| ONNX graph | ONNX Runtime adapter | `skeleton` | Inspection and runtime diagnostics only |
| TensorRT plan | TensorRT adapter | `skeleton` | Plan detection and diagnostics only |

## Validation

Run the default repository checks:

```bash
cargo fmt --all -- --check
cargo check --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
./scripts/validate_json_artifacts.py
```

Real-model validation is opt-in and must not silently skip when used as release
evidence:

```bash
python3 -m pip install -r requirements/compat-smoke.txt

BLOOM_REQUIRE_MODEL=1 \
BLOOM_MODEL_PATH=/path/to/model.gguf \
./scripts/ci_smoke_test.sh

BLOOM_REQUIRE_MODEL=1 \
BLOOM_MODEL_PATH=/path/to/model.gguf \
./scripts/openai_compat_smoke.py --require-openai-sdk

BLOOM_REQUIRE_MODEL=1 \
BLOOM_MODEL_PATH=/path/to/embedding-model \
./scripts/openai_compat_smoke.py --embedding-only --require-openai-sdk

./scripts/test_trained_embedding_runtime.sh --require-official-clients

BLOOM_REQUIRE_MODEL=1 \
BLOOM_MODEL_PATH=/path/to/model.gguf \
./scripts/ollama_compat_smoke.py --require-model --require-ollama-sdk
```

Promotion to `stable` requires a pinned model source and hash, a reproducible
command, successful task-specific quality evidence, and an appropriate
benchmark record. Generation profiles report dtype, quantization, TTFT, TBT,
throughput, and peak memory; embedding profiles report native width, context,
semantic/rerank margins, latency, and memory accounting. See
[RELEASE.md](../RELEASE.md) for the release gate.
